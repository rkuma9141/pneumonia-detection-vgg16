# 🫁 AI-Based Pneumonia Detection from Chest X-rays

## 🚀 Deep Learning | VGG16 | Transfer Learning | CNN | ANN | FastAPI

An AI-powered web application that detects **Pneumonia from Chest X-ray images** using Deep Learning and Computer Vision.

The project uses a **VGG16-based CNN model with Transfer Learning, Fine-Tuning, Class Weight and Threshold Optimization**. The trained model is integrated with a **FastAPI backend** and a modern **HTML, CSS and JavaScript frontend** for real-time prediction.
